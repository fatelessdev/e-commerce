# XILAR — Design Philosophy & Engineering Aesthetics

This document outlines the core design philosophy, visual direction, motion system, and interactive patterns that define the XILAR shopping experience. Refer to this document before creating, modifying, or refactoring any client-side UI components.

---

## 1. Brand Personality & Core Intent

*   **Premium Streetwear Editorial**: We blend the raw, streetwise energy of Indian streetwear (primarily targeting Gen-Z and young millennials) with the composed, clean structure of a luxury design house.
*   **Minimal but Engaging**: Prioritize clean typography and full-bleed image content over heavy boxes, borders, and visual clutter. Use UI transitions and AI-native micro-interactions to create delight.
*   **The Crimson Accent Signal**: Treat the primary crimson/red accent color (`--red`, `.bg-red-accent`) with extreme restraint. It is a directional signal reserved for active interaction states (CTAs, bargain triggers, high-priority status updates), never a dominant layout or background color.
*   **Anti-Reference**: Do not look like a discount marketplace. No constant promotional banners, flashing badges, or cluttered product tags. We show value through smart, gamified AI bargaining rather than aggressive discount shouting.

## 2. Aesthetic System & Tokens

### Color Tokens
*   **Dark Mode (Default)**: Primary background `oklch(0.115 0.01 30)`. Foreground text `oklch(0.93 0.006 60)`. Border lines use translucent neutral tokens (`rgba(var(--border), 0.6)`) to minimize visual noise.
*   **Light Mode**: Primary background `oklch(0.985 0.003 60)`. Foreground text `oklch(0.14 0.012 30)`.
*   **Surfaces**: Favor solid, muted backgrounds. Avoid heavy, colored glassmorphism or distraction-heavy gradients. Low-opacity grain overlays are acceptable to add texture.

### Typography
*   **Outfits Font**: Outfit is the global sans-serif typeface used across all layouts.
*   **Logotype**: Uses `Instrument Serif` (`font-[family-name:var(--font-instrument-serif)]`) for the logo ("Xilar") to introduce an editorial-contrast feel.
*   **Headline/Hero**: Heavy tracking and weight (weights 800-900), uppercase, tight line heights (`leading-[0.84]` to `leading-[0.96]`).
*   **Utility/Labels**: Uppercase micro-labels with wide letter spacing (`tracking-[0.15em]` to `tracking-[0.42em]`).
*   **Pricing**: Tabular numbers for price comparison. Always formatted in Indian Rupees (e.g. `₹799` or `Rs. 799`).

### Layout Rhythm
*   **Airy Columns**: Generous section spacing (`py-14` to `py-28`) and consistent horizontal gutters (`px-4`, `md:px-8`, `lg:px-12`).
*   **Product Framing**: Clean, borderless product cards with a `3:4` or `4:5` aspect ratio. Images are centered, and text details are tucked underneath with clean truncation and tabular pricing.

## 3. Interactive Mechanics & Page Studies

The XILAR experience is anchored by several signature interactive elements:

### A. 3-Panel Draggable Hero (`components/features/hero.tsx`)
*   **Desktop Concept**: A 3-panel split container where the active slide dominates the center. Side panels show cropped previews of previous and next slides.
*   **Mechanics**:
    *   Active slide supports drag gestures (`drag="x"` from Framer Motion).
    *   Clicking side panels triggers smooth GSAP/Framer Motion panel resizing and transition.
    *   Title and text details stagger and fade-in with a blur-to-sharp animation (`filter: "blur(6px)"` to `blur(0px)`) using an expo-out ease (`cubic-bezier(0.32, 0.72, 0, 1)`).

### B. Draggable Infinite Canvas Gallery (`components/features/gallery-client.tsx`)
*   **Infinite Tile Loading**: Renders a virtual grid coordinates-wise on a viewport. Drags translate the canvas (`translate3d`) using custom inertial calculations (momentum physics on release).
*   **Scatter-to-Gather Intro**: When loading, tiles are scattered off-center with randomized scales, opacities, and rotations, then beautifully animate to their grid positions.
*   **FLIP Lightbox Expansion**: Clicking a card triggers a FLIP animation. The card dynamically morphs from its viewport-relative bounds to a full screen modal. Detailed text and button overlays stagger vertically (`yPercent: 110` to `0%`).

### C. Angled Parallax Moving Band (`components/features/dec2024-gallery-band.tsx`)
*   **Visual Direction**: Multiple horizontal rows of images rotated at a sharp `28deg` angle and scaled up to span the layout.
*   **Parallax Mechanics**: Synchronized to scroll position using GSAP ScrollTrigger. Alternating rows slide in opposite directions (`index % 2 === 0 ? 1 : -1`) relative to the viewport scroll delta, providing a dynamic sense of depth.

### D. Scroll-Directional Marquee (`components/effects/directional-marquee.tsx`)
*   **Directional Memory**: A text marquee containing high-contrast SVGs that track scroll delta.
*   **Mechanics**:
    *   Scrolling down plays the marquee timeline forwards.
    *   Scrolling up reverses the marquee timeline (`timeScale` toggles to `-1`) and rotates the glyphs (`rotate(90deg)` to `rotate(-90deg)`) dynamically.

### E. 3D Mobile Navigation Reveal (`app/navbar.tsx`)
*   **Visual State**: A full-bleed editorial navigation menu that slides open.
*   **Transition Mechanics**:
    *   Revealed using a custom GSAP polygon clip-path sweep (`clipPath: "polygon(0% 0%, 100% 0%, 100% 175%, 0% 100%)"`).
    *   The main content container under the menu shifts, scales, and rotates slightly (`rotation: 10, x: 300, y: 450, scale: 1.5`) to create a 3D perspective depth effect.
    *   Hovering or focusing over main items updates a high-contrast preview image in the background with a spring-like ease.

### F. Fullscreen Typography-First Search Overlay (`app/navbar.tsx`)
*   **Visual State**: Fullscreen overlay with an input field taking up the center of the screen in a massive uppercase typeface (`WHAT ARE YOU LOOKING FOR?`).
*   **Features**: Includes a loading state indicator, top matches displaying inline search results with images, and trending search term chips.

### G. Video Reels (`components/features/shop-the-reels.tsx`)
*   **Visual State**: A horizontal snap-scroller of vertical video cards.
*   **Interactions**: Includes an audio toggle overlay. Tapping one video unmutes it, pauses and mutes all other video cards, and displays a floating purchase overlay card with blur filters (`backdrop-blur-md`).

## 4. Performance & Engineering Guidelines

Premium visuals must never compromise page performance. Implement the following design-engineering safeguards:

1.  **Intersection Observer Lifecycle Management**:
    *   Any animation loop (e.g. marquees, moving bands, scrolling previews) or video playback (reels) must use `IntersectionObserver` to pause updates immediately when elements exit the viewport.
    *   Disable or kill GSAP ScrollTriggers when navigation drawer panels are open.
2.  **Reduced Motion Support**:
    *   Always respect `prefers-reduced-motion` using the React hook (`useReducedMotion()` from Framer Motion).
    *   If reduced motion is active, bypass heavy translations, 3D rotations, and clip-path polygon sweeps. Provide instant opacity fades and immediate style changes.
3.  **Scroll & State Restoration**:
    *   Catalog pages (`ShopClient`) must store scroll offsets, filters (size, category, search), and visible pagination counts in `sessionStorage` before navigating to product details.
    *   On return navigation, read the state and restore scroll position smoothly (`window.scrollTo({ top: saved.scrollY, behavior: "smooth" })`).
4.  **Debouncing and API Request Cancellation**:
    *   Active search inputs must debounce requests (minimum 250ms) and use `AbortController` signals to cancel outstanding network operations if the query changes.
5.  **Dynamic Imports**:
    *   Decompose non-critical interactive components (e.g. Reels, canvas grids, sliders) into separate files and import them using Next.js `dynamic()` with a low-noise skeletal loading layout.
