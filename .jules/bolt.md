## 2024-03-01 - Avoid O(N) array lookups in render functions
**Learning:** External un-memoized utility functions (like `getVariantStock` or `isColorAvailable`) that perform O(N) operations using `.find()` over nested arrays (e.g., product variants) inside render blocks bypass the React Compiler's optimizations. This leads to unnecessary repetitive O(N*M) overhead during React renders when mapping over items like color swatches.
**Action:** Always pre-compute and memoize data structures, like `Map`, using `useMemo` for O(1) key lookups within components (e.g., `const variantMap = useMemo(() => new Map(...), [variants])`). When dealing with the React Compiler, extract nested arrays to local variables to use in dependency arrays to avoid optional chaining mismatch warnings.
