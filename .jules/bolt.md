## 2024-06-25 - React Component O(N) Repetitive Lookup Optimization
**Learning:** Repetitive array traversals inside render loops (like finding a specific variant from an array for every color/size option) are a hidden performance bottleneck, especially when the component renders lists or complex interactive selections (like in combo pages). Relying on O(N) array `.find()` during each render cycle quickly multiplies to a large overhead.
**Action:** When a React Client component frequently looks up specific composite properties (e.g., matching both `size` and `color` of a variant), use `useMemo` to construct a `Map` indexed by a composite string key (e.g., `${size}|${color}`). This reduces O(N) traversals to O(1) direct lookups. Always extract the target array to a local variable to avoid `useMemo` dependency mismatch warnings caused by optional chaining.
