## 2024-06-20 - Optimizing Combo Variants Find Array Iteration
**Learning:** `Array.prototype.find()` operations within render loops or `.map()` function render paths can cause expensive O(N) linear time lookups per element rendered. Specifically in `combo-client.tsx` and `combo-section.tsx`, fetching variant stock dynamically by iterating through a `variants` array of potential length `S x C` (sizes times colors) during every UI redraw, for every size and color combination, significantly impacts performance.
**Action:** Always pre-compute composite key lookups via `useMemo` into a JavaScript `Map` before complex component rendering cycles to optimize lookups to O(1) constant time. Note that since `product` variants might be deeply nested in combos, `useMemo` should only be updated on the exact variants array dependencies to prevent unneeded recalculations.
