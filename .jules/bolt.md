## 2025-03-01 - Optimizing React Re-renders with Memoized Maps
**Learning:** During the optimization of array traversals in React components with deep object structures (like variant arrays for colors/sizes), optional chaining (`?.`) within dependency arrays for `useMemo` or `useCallback` interrupts the React Compiler from fully optimizing the component tree. This happens because the React Compiler struggles to accurately match the potentially undefined dependencies correctly, leading to unnecessary re-renders.
**Action:** When extracting nested structures for memoized components (e.g. `const variants = combo?.productA.variants`), assign the extracted nested array to a distinct variable before usage (`const variantsA = combo?.productA.variants`). Then, use this distinct variable (`variantsA`) in the `useMemo` dependency array (`[variantsA]`) without the optional chaining operator to preserve the compiler's expected optimization paths and accurately track dependency references.
