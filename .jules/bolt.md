## 2024-03-24 - React Compiler Optimization
**Learning:** When manually memoizing complex array structures (like product variants) for O(1) lookups via `useMemo` in components optimized by the React Compiler, using optional chaining (e.g., `combo?.product.variants`) directly in the dependency array causes dependency mismatch warnings and prevents full optimization. Additionally, iterative lookups inside render loops (O(N)) cause severe performance degradation for complex items like combos.
**Action:** Always extract nested arrays to a local variable first (e.g., `const variants = combo?.product.variants;`) and use that variable in the dependency array for `useMemo`. When optimizing repetitive data lookups (e.g. variants, stocks), use a memoized `Map` to index data by a composite key (e.g. `size|color`) for O(1) access instead of O(N) array traversals.
