## 2024-05-24 - Optimizing Repetitive Array Lookups with Composite Key Maps
**Learning:** The React Compiler can fail to optimize `useMemo` dependencies if optional chaining (`?.`) is used directly in the dependency array (e.g., `[combo?.productA?.variants]`), causing mismatch warnings. Furthermore, repetitive `Array.prototype.find()` operations within render loops (like rendering size or color options) cause O(N) overhead which compounds per item rendered.
**Action:** Extract nested arrays to local variables (e.g., `const variantsA = combo.productA.variants;`) before passing them to `useMemo`. Construct a memoized `Map` using string interpolated composite keys (e.g., \`\${size}|\${color}\`) which safely handles null values, creating an O(1) lookup table that drastically reduces computation during renders without triggering compiler warnings.
