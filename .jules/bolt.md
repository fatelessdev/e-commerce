## 2024-06-25 - O(1) Repetitive Variant Lookups in React
**Learning:** In complex React client components, repetitive lookups inside loops/maps (`.find` inside `.map` for colors/sizes) create hidden O(N*M) bottlenecks during frequent re-renders. Additionally, the React Compiler expects clean dependency arrays for hooks like `useMemo`; using optional chaining (e.g., `combo?.product.variants`) inside `useMemo` arrays can break the compiler optimization.
**Action:** Always extract the target nested array to a local variable to bypass optional chaining, and map composite keys to values using `useMemo` returning a standard Javascript `Map`. For example, `variantMap.set('${size}|${color}', stock)` creates an O(1) index, replacing O(N) array traversals for each UI element map cycle.
