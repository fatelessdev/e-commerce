## 2024-05-16 - React Compiler Dependency Mismatch with Optional Chaining
**Learning:** When applying manual memoization (`useMemo`) to index child arrays (like `product.variants`) within components processed by Next.js/React Compiler, including optional chaining in the dependency array (e.g., `[combo.productA?.variants]`) causes the compiler to skip optimization due to dependency mismatches.
**Action:** Always verify inferred dependencies and strictly avoid optional chaining in manual hook dependency arrays (use `[combo.productA.variants]` instead) to ensure the React Compiler successfully preserves optimizations.
