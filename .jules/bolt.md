## 2024-06-19 - React Compiler and useMemo dependencies\n**Learning:** When using manual memoization (`useMemo`, `useCallback`) in components optimized by the React Compiler, using optional chaining (`?.`) in dependency arrays prevents compiler optimization and causes dependency mismatch warnings. \n**Action:** Extract the target nested array to a local variable (e.g., `const variantsA = combo ? combo.productA.variants : undefined;`) and use that variable in the dependency array to ensure the React Compiler can effectively optimize the component.
