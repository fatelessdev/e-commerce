## 2025-02-12 - Memoizing React Context Derivations
**Learning:** In React components, values derived directly from state arrays via O(N) operations like `.reduce()` that are placed directly into a Context Provider's `value` prop will cause the entire context to recalculate and all consumers to re-render on *every* single render of the Provider, even if the underlying state array didn't change (because the array reference might be the same but the `value` object reference changes).
**Action:** When creating React Context values derived from state arrays, wrap the derivations (such as O(N) array reductions via `.reduce()`) in `useMemo`, and wrap context mutation functions in `useCallback`. This maintains stable references, prevents unnecessary recalculations across the entire consumer tree on every render, and satisfies `exhaustive-deps` lint rules.
