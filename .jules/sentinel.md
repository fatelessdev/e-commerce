## 2025-02-14 - Admin Actions Missing requireAdmin() Authorization Checks
**Vulnerability:** Found multiple server actions (`getProductsPage`, `getUserStoreCredits`) exported in `lib/actions/admin.ts` that were missing the `await requireAdmin()` authorization check. Next.js server actions are publicly accessible endpoints by default, meaning any unauthenticated user could invoke these actions and access admin-level functionality or sensitive data.
**Learning:** Even though server actions reside in a file named `admin.ts`, they are still just API endpoints. The file location provides no security boundary. Every single exported server action must independently enforce its authorization requirements.
**Prevention:** Always verify that every exported server action explicitly calls the required authorization function (like `await requireAdmin()`) as its first statement. Consider using higher-order functions or middleware patterns for server actions to enforce authorization systematically rather than relying on manual checks inside each function.
